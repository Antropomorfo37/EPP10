Capítulos del libro

Cada grupo o clase (p. ej. «Generación 2019» o «3.º B — 2024/25») forma un capítulo. Ordénalos cronológicamente con las flechas.

Para tandas históricas elige «Solo año» (p. ej. 2019) o «Sin fecha»: el capítulo ya aporta el contexto.

No se pudo abrir el almacenamiento local

Esta aplicación guarda todo en tu navegador (IndexedDB) y no ha podido abrirlo.

  • Prueba con Chrome, Edge o Firefox actualizados.
  • Evita el modo de navegación privada/incógnito.
  • Alternativa 100 % local: sirve la carpeta con python3 -m http.server 8000 y abre http://localhost:8000/.
